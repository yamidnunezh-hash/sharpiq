¿Cómo usar este panel?

  1. Rellena el formulario del tipo de evento que necesitas
  2. Pulsa Generar Código
  3. Pulsa Copiar
  4. Abre datos.js con el Bloc de Notas
  5. Pega el texto dentro de los corchetes [ ] de la sección correcta
  6. Guarda el archivo → recarga la web

¿Dónde pego el texto en datos.js?

  1. Para Próximos Eventos: busca PROXIMOS_EVENTOS = [ y pega antes del último evento (antes del último } seguido de ])
  2. Para el Historial: busca PREDICCIONES_HISTORIAL = [ y pega al principio, justo después del primer [
  3. Asegúrate de que cada bloque termina con una coma , (ya está incluida en el texto generado)
  4. Guarda datos.js → recarga la web y listo
